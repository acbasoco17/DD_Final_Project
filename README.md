# Sound Pal

## Introduction
The motivation behind this project is to create a platform where users can
share music they are listening to with friends, explore new music and leave
reviews. The website would contain music across all genres. Users would be able
to make an account where they could save the music they’ve listened to. Not only
can they save music they’ve listened to, they can leave ratings and reviews to other
listeners. The idea is to provide a way for music lovers to connect over music. The
website allows users to search through both songs and artists. They can also make
friends and see what their friends are listening to.

## Database Setup
1. Open MySQL Workbench
2. Click “Local Instance”
3. Click the folder icon near the top left of the text box.
4. Find the Sound_Pal.sql file and click open.
5. Click the lightening bolt to run it and make sure there are no errors.
6. Go back to the home

## Website Setup
1. Make sure php is installed on device
2. Open up the project files in VSCode
3. Download the extensions in VSCode
  a. Live Server
  b. PHP Server
4. Go to index.php file
5. Change the username and password field
6. Go to music.php file
7. Right click
8. Click “PHP Server: Serve Project”
a. If you have already served this project, you will need to click “PHP
Server: Serve Project”
9. All done!
